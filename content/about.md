## 안녕하세요, 저는 김형준입니다

컴퓨터인공지능학과에서 공부하고 있습니다.

이 사이트는 초급프로젝트 과목 과제로 Hugo 테마를 이용해 만든 저의 포트폴리오 입니다.

## 관심 분야

### 축구 관련 웹 개발

제 아버지는 한 때 축구 심판을 하셨습니다.
아버지가 맡은 축구경기를을 TV와 현장에서 실시간으로 보며 축구에 대한 관심이 커졌습니다.
저는 선수들의 장단점과 능력을 한눈에 볼 수 있는 웹을 만들어 보고 싶습니다.

### 인공지능을 이용한 스포츠 데이터 분석

축구 경기 중 실시간으로 선수들의 움직임을 인공지능을 통해 분석해서 평점을 매겨보고 싶습니다.

## 역량

- **Git/GitHub 기본 사용**: 이번 과제에서 저장소를 만들고
  기능 단위로 커밋·push하며 GitHub Actions 배포 결과를 확인했습니다.

- **자료구조·알고리즘 (사용 언어: C언어)**: 알고리즘 수업에서
  이진 검색 트리를 직접 작성했습니다.

- **HTML/CSS 기초**: TA 시간에 HTML과 CSS로 자기소개 페이지를 만들었습니다.
  프로필과 취미 목록을 Flexbox로 배치하고, 미디어 쿼리로 화면 폭이 좁아지면
  배치가 바뀌는 반응형 레이아웃과 버튼 hover 효과를 적용했습니다.
  ([실습 페이지](../ta-intro/))
